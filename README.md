# Polestar 河林（部落）路线

2.0.20 版：修正乔格扎克两颗头颅的日志计数。乔姆-乔姆的接取箭头指向洞穴深处，护送终点沿用营地。西南龙洞的龙晶、烬鳞雏龙和烬鳞战士分别指向洞内目标。龙晶顺路提示只在河林室外显示。

适用于《魔兽世界》Forever 的简体中文河林部落升级路线，覆盖 36–46 级。需要先安装 [Polestar Guides](https://www.curseforge.com/wow/addons/polestar)。

## 用 WowUp 安装

1. 在 WowUp 顶部选择 **WoW Forever**。
2. 打开 **Get Addons → Install from URL**，粘贴本仓库地址并安装。
3. 在 **My Addons** 中右键这个插件，开启 **Auto Update**。以后发布到本仓库的正式版本会由 WowUp 检查并更新。
4. 进入游戏后，在 Polestar 里打开「河林（部落）· 连续完整路线」。

也可以从 [Releases](https://github.com/ufolyx-niper/PolestarPack_Riverglades/releases/latest) 下载以 `-forever.zip` 结尾的安装包，解压到 Forever 客户端的 `Interface/AddOns`。
